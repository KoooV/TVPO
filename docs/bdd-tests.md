# BDD / ATDD — кратко

Сценарии (Коротко: Условие → Действие → Ожидаемый результат)
1. Успешный голос: создано (Лучший цвет: Красный,Синий) → user1 голосует за Красный → Красный = 1
2. Дубликат: создано (A,B) → u1: A, затем u1: B → второй голос запрещён (DuplicateVote)
3. Неизвестная опция: создано (A,B) → u1 голосует X → UnknownOption
4. Закрыт: опрос закрыт → попытка голосовать → PollClosed
5. Несуществующий pollId → попытка голосовать/результат → PollNotFound
6. Множественные: u1→A,u2→B,u3→A → A=2,B=1,C=0

Шаги → методы
- Given создано... → `PollService.createPoll(...)` → `Poll` (конструктор)
- When участник голосует → `PollService.vote(...)` → `Poll.registerVote(...)`
- Then результат → `PollService.results(...)` → `Poll.getResults()`

Изоляция сценариев
- Рекомендация: очищать состояние `PollService` между сценариями (хук `@Before` вызывает тестовый `clearStore()`), либо использовать `@DirtiesContext`.
